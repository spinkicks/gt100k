# Art credits

The images in this directory (`map.png`, `cabin-math.png`, and any additional
`cabin-*.png` files) are AI-generated placeholder art produced via the
TrueFoundry image gateway (`https://tfy.promptlens.trilogy.com`), using the
`gpt-image-1` model (or `gemini-3-pro-image-preview` where noted), by running
`scripts/gen-art.mjs` from this app's directory.

They are first-pass placeholder art for the game's world map and cabin
interior backgrounds, generated for prototyping and demo purposes. Regenerate
or replace with commissioned/licensed art before any production use.
