Our spiky POV

You can't ask a child what they love, and you can't force it.

So measure what they return to, protect them from pressure, and prove the work by recording how it was made.

  1. What a child returns to beats what they pick, or say they like.
  2. You can't read motivation from behaviour, so we build the tool for the guide, not a detector for the child.
  3. Burnout comes from pressure, not hours: start early, but never lock in early.
  4. An over-detailed record is surveillance; a simple honest one is proof of process, so nothing child-facing is scored.
  5. Tamper-proof logs are easy; the missing piece is a trust anchor: an in-person defense.

Live · EvidenceGraph

Record the making, not the result.

A Google Docs extension captures the work as it happens, into a graph that can't be quietly rewritten.

3:15–4:15 · FELIPE drives. Palette is cool now — this is the second product. Frame in one line: "A finished artifact can't tell you who made it — a child, an AI, a tutor, or paid help. Detecting the AI is the reflex, and it fails the wrong kids, so we never point a detector at a child. Instead we record the making." LIVE, macro steps: • Write in a real Google Doc with the extension on. It captures steps automatically — no extra work for the child. "This is the same idea as version history, except each step's id IS its content (a SHA-256 fingerprint), so it can't be back-dated or silently edited." • It's an append-only Merkle graph: a correction is a NEW node pointing back, never a rewrite. The whole graph rolls up to one root a verifier recomputes independently. It's its own engine, a separate repo from PassionLab. • Tamper flip (the most convincing 10 seconds): change one saved step → the root mismatches and the graph visibly fractures → undo restores it. "That's how you know nothing was edited since." Honest scope in a breath: "This proves nobody altered the record. It does NOT prove the child understood the work — that's what the in-person reflection is for. Declared help is fine; only hidden help passed off as solo is the problem."
